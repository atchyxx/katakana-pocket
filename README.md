# カタカナ ポケット

日本の小学生向けに、カタカナを「よむ・えらぶ・かく」で練習するブラウザアプリです。

## できること

- **よむ**：カタカナとひらがなの対応、音声読み上げ
- **えらぶ**：5問クイズと選び直し
- **かく**：書き順の連続再生・1画ずつ再生、番号付きのお手本、指・ペン・マウスでのなぞり書き
- 1画目ピンク、2画目青、3画目オレンジ、4画目緑、5画目紫、6画目茶色
- 「1画もどす」「ぜんぶけす」で書き直し
- 基本46文字、濁音・半濁音、小さい文字、単語に対応

## 起動方法

このリポジトリをダウンロードし、展開したフォルダの `index.html` をブラウザで開いてください。
インストールやビルドは不要です。HTML・CSS・JavaScriptのみで動作します。

スマートフォン・タブレットでは、静的Webサイトとして配信したURLから開く方法を推奨します。
このリポジトリへの保存だけでは、GitHub Pagesの配信は開始されません。

## ファイル

| ファイル | 役割 |
| --- | --- |
| index.html | ページとスクリプトの読み込み |
| style.css | 配色と画面サイズへの対応 |
| app.js | 文字一覧・音声・クイズ |
| strokes.js | 文字ごとの筆順と描画用の線データ |
| writing.js | 書き順アニメーションとなぞり書き |

## 利用上の仕様

- 音声はブラウザの音声読み上げ機能を利用します。日本語音声の有無や発音は端末・ブラウザに依存します。
- なぞり書きでは指やペンを離すごとに次の画の色へ進みます。
- 文字の形・書き順・正確さの自動採点は行いません。
- お手本は筆順を示す簡略化した線です。授業では採用している教科書のお手本も確認してください。
- 学習記録の保存、アカウント登録、分析ツールはアプリに実装していません。
